# Изменения

## v0.1.0 — 2026-09-28

Первый релиз.

- Оркестратор `orch` по схеме «опрос → план → тесты до кода → код до зелёного → ревью → слияние».
- Параллельные воркеры, каждый в своём git worktree. Зависимые подзадачи стартуют, когда их зависимости уже слиты.
- «Готово» определяется только по тестам: тесты, зелёные до кода, отклоняются; правки тестов воркером откатываются;
  слияние, сломавшее другие тесты, откатывается.
- Модели вызываются через `claude -p --restricted` под вашим аккаунтом Claude, без API-ключа.
  По умолчанию мозг — Fable 5.1, воркеры — Opus 5.5 (настраивается в `orch.toml`).
- Режим чата `/orch` для Claude Code: `orch install-skill`.
- Команды `orch init`, `orch run` (в том числе с готовым планом `--plan`), `orch status`, `orch resume`.
- Проекты на Python и JavaScript (pytest, npm test, node --test), Windows и Linux.
